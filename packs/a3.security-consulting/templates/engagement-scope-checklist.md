# 착수 범위 · 수행 규칙 체크리스트: {{title}}

> 고객명·시스템명·IP 는 쓰지 않는다 (비식별). 고객 유형(금융/공공/제조/플랫폼)과 `<시스템A>`, `<내부IP>` 같은 자리표시자만 쓴다. 고객 코드·자격증명도 붙여 넣지 않는다.

## 범위
- [ ] 대상 자산 유형과 수량이 문서로 확정됐다 (포함 / 제외 목록)
- [ ] 제3자 소유 자산(클라우드, 위탁 운영)의 사전 승인이 확인됐다
- [ ] 진단 유형과 깊이(취약점 진단 / 모의해킹, 인증 유무)가 합의됐다

## 수행 규칙 (RoE)
- [ ] 허용·금지 행위 (서비스 거부, 사회공학, 운영 데이터 변경 등)
- [ ] 수행 시간대 · 변경 금지 기간
- [ ] 중단 조건과 재개 절차
- [ ] 비상 연락 체계 (양측 역할 기준, 실명은 노트에 적지 않는다)

## 데이터 취급
- [ ] 수행 중 접한 데이터의 보관·반출·파기 기준
- [ ] 증적 저장 위치와 접근 권한
- [ ] 보고서 배포 범위와 전달 방식

## 종료
- [ ] 생성한 계정·파일·설정의 정리 목록 관리 방법
- [ ] 치명적 발견의 즉시 통보 기준
