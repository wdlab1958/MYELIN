## 모든 오류는 위치를 가진다
잘못된 Pack 13종이 모두 거부되며, 오류마다 필드 경로가 붙는다. 예:
- `domains[0].id` — Domain ID 형식 위반
- `domains[0].interview_bank` — 참조 파일 없음 / 해당 Domain 질문 없음
- `domains[0].taxonomy_seed` — Pack 밖을 가리키는 경로
- `pack.yaml:8:13` — YAML 문법 오류 위치

처음 구현에서는 Pack 전체 수준 검증 오류가 `<root>` 로만 표시되어 "필드 경로 포함" 기준을 못 맞췄다.
필드 단위 검증으로 바꿔 `domains`, `requires` 등으로 나오게 했다.
