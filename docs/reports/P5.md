## 가드레일을 검사로
- `--lint`: `design/src` · `design/gallery` · `packages/myelin-hub/web/src`(P6)에서 색 리터럴(`#hex`, `rgb()`, `hsl()`) 금지,
  네온 변수를 `color:` 에 쓰는 것 금지. 위반 시 Gate FAIL.
- `--check`: 커밋된 생성물이 tokens.json과 다르면 FAIL — 생성 파일 직접 수정 방지.
- 스크린샷 최신성: 찍을 때 갤러리·CSS의 sha256을 `gallery.sha256` 에 기록, Gate가 현재 파일과 비교한다.
- Pack accent 6종(ADR-0004) = 토큰 accent·glow 키 일치를 테스트로 확인 (Domain Orb 색 누락 방지).
