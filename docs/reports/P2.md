## 산출물

### `myelin` CLI (`packages/myelin-cli`)
- `myelin init` — 3+1 Domain 마법사(이름·팀·이메일·primary/research/growth, 사용 가능 Domain 목록 표시). 비대화형(`-y`)은 동일 플래그, 누락 시 exit 2. `--pack` 추가 설치, `--dry-run`, `--packs-dir`. **기존 파일이 하나라도 있으면 아무것도 쓰지 않고 중단**(fail-closed, 'x' 모드 생성).
- `myelin add-domain <ID>` — Pack이 선언한 Domain을 `domains.extra`에 추가. MOC·Domain 템플릿 생성, taxonomy.md·CLAUDE.md 재생성(personal 블록 보존), 기존 노트·MOC 불변. 다의성은 `--pack`으로 해소, 기존 MOC는 덮어쓰지 않음.
- `myelin doctor` — 규칙 8종, `--json`, `--strict`(warning도 실패). 오류 시 exit 1.
- `myelin stats` — §11.1 지표 7종(표/JSON), `--today`.
- 종료 코드: 0 성공 · 1 doctor 위반 · 2 사용 오류/차단. 테스트 훅 `MYELIN_NOW`.
