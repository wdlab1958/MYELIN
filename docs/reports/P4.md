## 보안 경계 — P3 Guard와 같은 정책을 MCP에도
MCP 결과는 Claude의 대화에 들어가 Anthropic으로 전송된다. 그래서:
1. **보호 노트(40_IP·confidential)는 색인 자체에 넣지 않는다.** 결과에서 거르는 방식이 아니다 — 필터에 버그가 있어도 나갈 내용이 없다.
   색인 DB에도 경로와 변경 시각만 남고 본문은 저장되지 않는다 (테스트로 확인).
2. `llm.route` 를 바꾸면 정책 서명이 바뀌어 **색인 전체를 다시 만든다**. 다시 닫으면 다시 사라진다.
3. `get_note` 는 정규화·realpath 후 Vault 안의 지식 노트만. `../../etc/passwd`, `myelin.yaml`, `.claude/`, `50_Journal`, 심볼릭 링크 탈출 → 모두 거부.
   보호 노트와 없는 노트는 **같은 메시지**로 거부한다 (존재 여부를 흘리지 않음).
4. `vault_stats` 는 숫자만 — 노트 경로·내용 없음.
5. `write_draft` 의 경로·Level 판정은 **Guard 모듈의 `check()` 를 그대로 호출**한다. 규칙을 두 곳에 구현하지 않는다.
   항상 `origin: claude`, `status: draft`, `00_Inbox/ai-drafts/`, 덮어쓰기 금지(`open('x')`).

## 한국어 검색
trigram 토크나이저로 조사가 붙은 단어("예산은")도 부분 문자열로 찾는다.
trigram은 3글자 미만을 못 찾으므로 "예산", "지연" 같은 2글자 검색어는 `LIKE` 로 보완했다 — 혼합 검색("WCET 예산")도 동작.

## 검증
- 프로토콜 수준: in-process `mcp.Client` + **실제 stdio 하위 프로세스** e2e (Claude Desktop/Code와 같은 방식).
- 기본 서버 도구 목록 = 읽기 5종 정확히 (Gate가 새 Vault로 확인).

## 진행 중 발견해 고친 것
- **MCP SDK 버전 차이:** SDK가 2.x로 바뀌어 `FastMCP` → `MCPServer`, 클라이언트 API도 변경되었다. 설치된 패키지 소스에서 확인하고 `mcp>=2.3,<3` 으로 고정했다.
- **도구 인자 인식 실패:** 오류 변환 데코레이터가 함수 시그니처를 가려서 SDK가 도구 인자를 `args/kwargs`로 인식했다 → `functools.wraps` 로 해결.
