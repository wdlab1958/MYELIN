## 산출물

### `myelin_core.index` — SQLite FTS5 색인 (T1)
- `<Vault>/.myelin/index.db`: `notes`(frontmatter 컬럼·body·mtime/size/sha256) · `note_domains` · `note_tags` · `links` · `parse_errors` · FTS5 `notes_fts`(trigram).
- 증분 갱신(mtime_ns, size 서명), 삭제 반영, 파싱 오류 캐시, 스키마 버전 불일치 시 재구축. 캐시이므로 삭제 후 재생성 가능.
- 하이브리드 검색: 3자 이상 토큰은 FTS MATCH(전부 인용 → 구문 주입 불가), 2자 이하 토큰(한국어 2음절)은 LIKE. 토큰 없음 = 오류(fail-closed). bm25 가중치 title 4 · body 1 · tags 2.
- `query()` Dataview 류 필터, `stats()` 는 전체 스캔 `compute_stats` 와 결과 동일(테스트).
- 스레드 안전: RLock 커넥션 파사드.

### `myelin-mcp` (T2~T7)
- `myelin-mcp --vault <path>` (stdio). `VaultService` 가 정책 계층: 경로 해석·경계, 기밀 정책, write_draft 게이트.
- 도구: `search_notes` · `get_note` · `query_frontmatter` · `list_domains` · `vault_stats` (+ `write_draft` opt-in). write_draft 는 `00_Inbox/ai-drafts/` 새 파일만, 템플릿 렌더, origin claude/status draft, 생성 후 색인 검증 실패 시 파일 삭제.
- 정책 스위치 `myelin.yaml mcp: {write_draft, expose_confidential}` (기본 둘 다 false).
