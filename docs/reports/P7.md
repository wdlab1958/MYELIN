## 설계 포인트
- **제안해도 Vault와 사용자의 Commons 작업 트리는 바뀌지 않는다.** 임시 index + `commit-tree` + `update-ref`(브랜치가 없을 때만)로 commit을 만든다. 테스트가 작업 트리·`.git/index` 바이트로 확인한다.
- **기기 밖으로 나가는 유일한 경로는 push다.** 제안과 분리된 두 번째 확인 버튼이며, API도 `confirm: true` 가 없으면 거부한다.
- PR을 MYELIN이 직접 만들지 않는다. git 호스트 API 토큰을 다루지 않기 위해서다. push 후 호스트가 PR 링크를 준다.
- **공개본에서 빼는 필드:** `share`·`source`·`projects` — 개인 문헌 노트 제목 같은 개인 Vault 구조가 새지 않게.
- **공개본에 넣는 필드:** `author`·`commons_of`(원 id)·`published` — 출처 보존 (§9.1).
