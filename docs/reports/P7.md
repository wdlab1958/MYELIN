- **`myelin_core.commons`** — Commons 골격(`init_commons`), Pack Registry(`registry/index.yaml`, `add_pack_to_registry`), 비식별 스캔(IP·이메일·전화·주민번호·시크릿·내부 URL·기밀 표시어 + `deid.yaml` 용어/정규식), 공개 하드 게이트(`check_publishable`), `publish_note`(publish/<id> 브랜치 1커밋, 출처 보존 필드, `--push`/`gh pr`), `propose_pack`(propose/<name>).

- **Hub** — `GET /api/commons/candidates`, `POST /api/commons/publish/{path}`(클릭 + `confirmed`), `GET /api/metrics`; Review Gate 의 "Commons 후보" 섹션(검사 결과·비식별 확인 체크·Commons 제안 버튼); 온보딩/첫 승격 이벤트 기록.
- **Packs** — `org.incident-response`(IR: 초동 대응·Timeline·IoC·포렌식·봉쇄/복구·Post-mortem, 템플릿 3종, 비식별 규칙 명시). `org.security-consulting` 은 Registry 등록 대상으로 확정(챔피언 서명 대기).
