## 옮긴 것
| 기능 | Desktop 구현 | 이번 구현 (차이) |
|---|---|---|
| **`_patches` 적용** | 구조화 patch + Hub 적용 | 같은 형식(`patch: 1`, append·replace·frontmatter) + **안전 검사 추가**: 대상 경로·링크·40_IP·confidential 거부, frontmatter는 허용 키만(status·origin 등 금지), verified 노트가 미검증 AI 노트를 새로 링크하면 거부, 원문 CRLF 보존, 화면 patch의 digest 확인, commit 실패 시 원복. `/link` 스킬 출력 계약을 구조화 형식으로 변경 (ADR-0010) |
| **Pack 진화 (pack-propose)** | 사용자의 Commons 작업 브랜치를 checkout 해서 commit | **작업 트리·현재 브랜치를 건드리지 않는** 임시 index commit (`propose/<pack>`), 개인 Pack만, 템플릿 허용 목록·비식별 검사 통과 필수, 확인(`--yes`/대화형) 필수, push는 별도 |
| **지표 집계** | owner 해시 기반 사용자 수 | 익명 제출 파일을 주 단위로 집계. **익명 형식이 아닌 파일은 거부** (추가 키·정확한 수·개인/reference Pack 이름) |
| **설치 시 플러그인·MCP·테마** | 기본 실행 | **플래그를 줄 때만**: `--vault`(테마 복사, 직접 고친 테마는 덮어쓰지 않음), `--claude`(플러그인 등록, `--vault` 와 함께면 MCP 등록) |
