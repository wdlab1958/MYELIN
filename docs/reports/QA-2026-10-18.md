### 2.5 Agent (Guard hook · MCP · Skill, 적대 테스트 394 + 91 + 24건)

**Guard(Write/Edit/NotebookEdit)** — 숨김 디렉터리(`50_Journal/.obsidian/x.md`), 줄바꿈·DEL·RTL 제어문자 경로, 비-.md 파일(`x.sh`, `.ipynb`), `_patches/applied|rejected/` 쓰기, NotebookEdit 의 두 번째 경로, `level:1`(공백 없음)·중복 `level:` 키가 모두 **허용되던 것을 차단**했다.

**Guard(Bash)** — 줄바꿈으로 구분된 두 번째 명령, `#` 뒤의 리다이렉션, `>&`/`>>&`/`|&`, `{ }`/`!`/`if`/`while`/변수 접두, `nohup`/`timeout`/`command` 래퍼, `find -delete/-exec`, `awk > file`, `sed --in-place`, stdin 스크립트(`bash -s`, `python3 -`, `curl | sh`), Vault 내부 스크립트 실행, `uv run python -c`, `wget`/`curl -o`, `mv --target-directory=`, glob 대상, git 비-읽기 서브커맨드(`-C`, `--amend`, `apply`, `am`, `update-ref`, `fetch`, `remote add` …)를 **차단**하고, git 은 허용 목록(읽기 전용 + `add`/`commit`)으로 바꿨다. stderr 가 닫혀도 exit 2 를 보장한다. 허용 확인: `ls`, `git status/diff/log`, `cat`, `grep`, `touch 00_Inbox/ai-drafts/x.md`, `tee 50_Journal/x.md`, `uv run pytest`, `make`.

**MCP** — 공개 노트의 백링크 목록에 `40_IP/`·confidential 노트의 **제목**이 새던 문제(`expose_confidential: false`)를 막았고, 제어문자 제목의 `write_draft`, 10 스레드 동시 호출(`sqlite3.InterfaceError`)을 고쳤다(core 의 락 안에서 행을 확정하도록 수정). 경로 순회·FTS 구문·SQL 주입·100 KB 질의·비-Vault 기동은 모두 정상 거부.

**Skills** — 7개 SKILL.md 의 Level·쓰기 범위가 `levels.SKILLS` 와 일치하고, 선언한 출력 경로가 실제 Guard 에서 최소 Level 에 허용·그 아래에서 차단되며, `_COMMON.md` 규칙과 fixture 출력이 frontmatter 스키마를 통과한다.

## 3. 받아들인 동작(수정하지 않음)

- Sub-MOC 검색에 `_MOC` 자신이 잡힌다(제목에 주제가 있으므로 정상).
- `cp 10_Domains/D1/a.md 00_Inbox/ai-drafts/b.md` 는 차단된다(모든 위치 인자를 대상으로 봄; `cat … > ai-drafts/x.md` 가 허용 형식).
- 전각 `＞` 는 bash 에서 리다이렉션이 아니므로 허용.
- 패키지 설치·Vault 밖 스크립트·네트워크 송신은 Guard 의 쓰기 정책 범위 밖(ADR-0005 알려진 제약, 릴리스 노트 명시).
- Pack `sub_mocs` 이름의 `/`·`..` 는 읽기 전용 `exists()` 에만 쓰이므로 스키마 변경(ADR)과 함께 이월.
