## 회고 (P0~P8)
**잘된 것**
- Phase-gated 프로토콜(PHASE_STATE + Gate 스크립트 + 태그)이 세션을 넘겨도 흔들리지 않았다. 미구현 Phase 의 Gate 가 fail-closed 로 FAIL 하는 설계가 실수 태그를 막았다.
- "Fail-closed 는 규칙이 아니라 장치"(정본 §1.2)를 세 경로(Guard·MCP·Hub)에서 같은 원칙으로 구현하고 각각 100% 차단 테스트로 고정했다.
- Pack = 데이터 원칙이 지켜졌다: Domain 추가(IR 등)에 코드 변경이 없었다.
- 토큰 단일 원천 + 대비 검사가 정본 값의 접근성 미달 3건을 조기에 드러냈다(ADR-0008).

**아쉬운 것 / 배운 것**
- 환경 결함(혼합 pyenv 설치)이 P4 에서 세그폴트로 나타났다 — 설치 스크립트의 자가 검사로 승화했지만 P0 에서 인터프리터 검증을 했어야 했다.
- P4 의 Pack 루트 중복 오류가 P6 까지 잠복했다 — 실제 사용 경로(e2e)가 늦게 생긴 탓. e2e 를 더 이른 Phase 에 두는 편이 낫다.
- 정본과 구현이 갈린 지점 7곳(ADR-0002 D1~D7, ADR-0008 값, ADR-0005 Level 누적, ADR-0007 기밀 opt-in, ADR-0009 헤더, ADR-0010 비식별 차단)은 모두 ADR 로 남겼다. **정본 Rev 2.1 개정 제안**이 v1.1 Backlog 의 첫 항목이다.
- 사람 참여 Gate(P7 파일럿, KIPRIS)는 자동화할 수 없다. 기록 도구를 만들어 Gate 를 "기록 파일 기반" 으로 바꾼 것이 현실적인 타협이었다.
