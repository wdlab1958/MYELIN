## 이번 점검에서 찾아 고친 것
| 발견 | 위험 | 조치 |
|---|---|---|
| **Pack 템플릿 = Obsidian에서 실행되는 코드** — Templater `<%* %>`·`tp.user`·`tp.system`·`tp.web` | 남의 Pack(조직·인터넷)을 설치하면 Vault를 열 때 임의 코드 실행 (T3/E3, High) | 로더가 템플릿 표현식을 허용 목록(`tp.date.now`, `tp.date.today`, `tp.file.title`)만 받는다. 템플릿 폴더의 링크 파일도 거부. invalid fixture #14와 단위 테스트를 추가했다 |
| **localhost = 안전 가정** | 같은 PC의 다른 OS 사용자·프로세스가 127.0.0.1 포트로 노트(40_IP 포함)를 GET 할 수 있었다 (I5) | 실행마다 임의 세션 토큰을 터미널 링크로만 전달하고, HttpOnly·SameSite=Strict 쿠키로 교환한다. `/api` 는 토큰이 없으면 401. Hub 인스턴스마다 쿠키 이름이 다르다 |
| **Gate가 주석을 값으로 읽음** | 상표 검토 칸이 비어 있는데 `reviewed_by:` 뒤 주석 때문에 PASS 로 판정 (fail-open) | 주석·따옴표·null을 제외하고 판정하도록 고쳤다. 회귀 테스트 추가 |
| **PyPI 이름 충돌** | `myelin`, `myelin-mcp` 는 다른 프로젝트다. `myelin-mcp` 는 "AI 에이전트용 기억 MCP"로 개념까지 비슷하다 | PyPI·npm에 배포하지 않고 git + lockfile 설치만 한다. 안내 문서에 `pip install` 금지를 명시했다 |
