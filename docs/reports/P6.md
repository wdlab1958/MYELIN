## 보안 경계 (ADR-0008)
- **Host 헤더 검사**(DNS rebinding), **POST만 쓰기**, POST에는 `X-Myelin-Intent: user` + 같은 출처 `Origin` + JSON 본문 필수.
  다른 웹사이트가 열려 있어도 Hub를 조작할 수 없다. CORS는 열지 않는다.
- CSP `default-src 'self'` (inline script·eval 차단 — e2e 중 Playwright의 eval 대기도 실제로 막혔다), `frame-ancestors 'none'`.
- 쓰기 API 목록을 테스트가 고정한다 — 새 POST를 추가하면 검토 없이 통과하지 못한다.
- 노트 본문은 HTML로 렌더링하지 않는다.
- **`llm.route`(기밀 → 로컬 경계)는 Hub에서 바꿀 수 없다.** 설정 화면은 Level과 MCP 초안 쓰기만 바꾼다.

## Review Gate 규칙 (ADR-0005 '노트 불변'의 유일한 예외)
- 화면에 표시한 노트의 id를 함께 보내야 승격된다 — 보지 않은 노트는 승격되지 않는다.
- Inbox 초안은 첫 Vault Domain 폴더로 이동, 반려는 `99_Archive/rejected/` 로 이동(`deprecated`). **삭제는 없다.**
- `origin: claude` 는 승격 후에도 유지 — AI가 쓴 것이라는 출처가 남고, 승격률 지표(목표 40~70%)의 근거가 된다.
- 거부(fail-closed): Vault 밖·심볼릭 링크·비노트 경로, 깨진 frontmatter, 검토 대기 아닌 상태, Vault Domain 없음,
  이동 대상 존재, `confidential + share`, **미검증 AI 노트를 링크하는 노트**, git 저장소 없음.

## 진행 중 발견해 고친 것
- e2e 대상 git 경로가 한글이라 `git show --name-status` 가 따옴표로 감싼 8진수 경로를 냈다 → `-z` 로 파싱.
- 이동 commit에서 rename 감지로 이전 경로가 빠졌다 → `--no-renames`.
- 대시보드 Verified 수에 MOC가 포함되었다 → `stats.verified_notes`(MOC 제외) 추가.
- CLI 테스트의 서버 실행 경로가 실제 uvicorn을 띄워 테스트가 멈췄다 → 실행부를 대체하고 Pack 탐색 실패를 별도 검사.

## 독립 보안 검토 (별도 에이전트) → 반영
구현을 보지 않은 검토 에이전트가 Hub·Review Gate를 공격자 관점에서 점검했다. 발견 6건을 모두 고치고 회귀 테스트를 추가했다.

| # | 발견 | 수정 |
|---|---|---|
| 1 | commit이 훅 등으로 실패하면 파일은 되돌려지지만 **stage가 남아** 사용자의 다음 commit에 섞임 | 실패 시 해당 경로 `git reset` |
| 2 | 승격이 CRLF 노트의 **모든 줄바꿈을 LF로** 바꿈 (본문 보존 검증이 정규화된 값끼리 비교) | 바이너리 읽기·쓰기, 닫는 줄부터 원문 그대로 이어 붙이고 원문 꼬리로 검증 |
| 3 | 미리 심어 둔 `.x.md.myelin-tmp` 심볼릭 링크를 따라 **Vault 밖 파일을 덮어씀** | `mkstemp`(임의 이름·O_EXCL) |
| 4 | 파일 이름의 `*`·`?`·`[` 가 pathspec 와일드카드로 해석되어 다른 파일이 stage됨 | `GIT_LITERAL_PATHSPECS=1` |
| 5 | Domain 폴더·`99_Archive/rejected` 가 심볼릭 링크면 Vault 밖에 씀 (git이 거부해 되돌려지긴 했음) | 대상 경로 링크 검사 + `O_NOFOLLOW` |
| 6 | 파일 이름의 제어 문자가 commit 메시지에 들어가고, `\x1f` 는 대시보드 500을 유발 | 제어 문자 경로 거부, `git log -z` + 제목을 마지막 필드로 |

확인된 안전 항목: Host 우회(`localhost.`, 빈 Host, 잘린 IPv6), CSRF(커스텀 헤더 + preflight 미응답), SPA 경로 탈출,
GET의 쓰기, `-` 로 시작하는 파일 이름의 git 옵션 주입, `llm.route` 변경, React의 HTML 주입.
