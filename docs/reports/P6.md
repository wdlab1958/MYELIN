## 산출물

### Hub API (`packages/myelin-hub/api`, `myelin-hub --vault <path> [--port 8787]`)
- 읽기: `/api/vault · stats · doctor · domains · notes · search · notes/{ref} · review · guard · git/log · git/status · packs · packs/{name} · settings`. 모두 `VaultIndex`/`VaultService` 와 같은 코어를 재사용.
- 쓰기(클릭 헤더 필수, 각 1 commit): `POST review/promote|reject/{path}` · `POST patches/{name}/apply|reject`(ADR-0006 append/replace/frontmatter, 실패 시 원복) · `PUT settings`(CLAUDE.md 재렌더, personal 블록 보존) · `PUT packs/{me.*}`(로더 검증 후 저장) · `POST onboarding`(`init_vault` + welcome 초안 + git init).
- localhost 전용, 빌드된 web 을 정적 서빙(SPA fallback).

### Hub Web (`packages/myelin-hub/web`, React 18 · Vite · TS · Tailwind + Emboss preset)
- **Dashboard** KPI 타일(verified·Review 대기·Guard 차단·파싱 오류) + §11.1 지표 표 + 최근 커밋.
- **My Domains** Domain Orb(accent glow) → Domain Map/MOC/Sub-MOC/노트 표.
- **Inbox / Review Gate** AI 초안·패치 제안 Review Row, Promote(Lime)/Reject, 승격 순간 myelinated 링 애니메이션 + commit 토스트.
- **Domain Packs** Registry 카드 + 개인 Pack(me.*) 편집기(검증/저장 commit).
- **Settings** Level(0~3)·MCP 스위치 저장(commit), Skill 개방 표.
- **온보딩 마법사** 이름·3+1 Domain·Level → Vault 생성(CLI `init` 과 동일 로직).
