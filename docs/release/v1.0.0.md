## 핵심 보장
- **verified 는 사람만 만든다** — Hub Review Gate에서 원문을 본 노트만 승격되고, 승격은 Vault git commit으로 남는다.
- **사용자 행위 없는 Vault 쓰기 0** — 화면을 보는 것만으로는 아무것도 바뀌지 않는다 (e2e로 확인).
- **confidential · 40_IP 는 Claude로 보내지 않는다** — Guard · MCP 색인 · 라우팅. Hub에서는 이 경계를 바꿀 수 없다.
- **공개는 개인의 행위** — 자격 미달 48조합 전부 차단, 비식별 자동 차단, 기기 밖으로 나가는 유일한 경로는 확인된 push.
- **Vault는 각자의 기기에** — 소스 폴더·다른 git 안에는 Vault를 만들지 않는다. Hub는 loopback + 세션 토큰.

## 알려진 제약
- **다크 모드 미지원** — Hub와 Obsidian 테마 모두 라이트 모드만 (토큰 구조는 대비해 둠).
- **Windows 기본 환경 미검증** — WSL2 사용. `install.sh` 는 macOS·Linux·WSL2용.
- **PyPI·npm 배포 없음** — git + lockfile 설치만. PyPI의 `myelin`, `myelin-mcp` 는 **다른 프로젝트**다 (`pip install myelin-mcp` 금지).
- **상표 미확정** — "MYELIN" 계열 이름이 같은 분야에 존재한다. KIPRIS 검토 전에는 조직 외부 홍보를 미룬다 ([기록](../legal/trademark-check.md)).
- **Team 모드 인증 없음** — Hub는 1인·localhost 전용. 원격 접속·다중 사용자는 v1.0 범위 밖.
- **Guard 차단 이벤트 미기록** — 차단 사유는 Claude에게만 반환된다.
- **Hub 화면 폭** — 1280px 이상 데스크톱 기준.
- **Hub 검색 없음** — 검색은 Obsidian과 MCP(`search_notes`)로.
- **조직 정책 미합의 상태의 기본값** — Commons 기본 꺼짐, 공개 가능 classification은 public·internal. §9.1 정책 합의 후 조정.
- **파일럿 미실시** — 사람 기준 "온보딩 15분"은 P7 파일럿에서 측정한다. 자동 측정(설치→첫 verified)은 수십 초.
- **빌드 도구 경보** — Tailwind 3·esbuild(dev 서버)의 dev 의존성 경보는 배포 번들과 무관 (위협 모델 T6, 수용).

## 업그레이드 · 호환
- 처음 공개되는 안정 버전이다. `myelin.yaml` 스키마 `myelin: 1`, lock `myelin_lock: 1`, Commons Registry `registry: 1`.
- v0.x 개발 버전으로 만든 Vault는 그대로 열린다 (새 설정 키 `commons.path`·`metrics.opt_in` 은 기본값).
